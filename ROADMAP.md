# Roadmap

This file lists the gaps in the evidence and what the site needs next. It is a repository file, not a site page; keep the gaps in step with the site's [Open questions](https://agentpractices.io/evidence/open-questions/) page.

## Gaps in the evidence

Each needs a primary study before a practice page can say anything about it.

- **Fresh session per step against one long session** on coding work. Long sessions lose instruction-following; no study compares the two directly.
- **A plan that works as a table of contents** pointing to per-step files, against one plan document.
- **Nested or path-scoped instruction files** against one root file.
- **Repository size as a cause.** Success falls on larger repositories in one benchmark, but size is mixed up with language and task type.
- **Search against a pre-built index** for code changes, not only for questions about code.
- **Team effects:** onboarding, drift and review cost of shared instruction files over months.
- **Whether instruction files help at all** beyond the few controlled tests, on more languages and agents.

## Site

- **Replication notes.** A short protocol for each gap above, so a reader can run the study.
- **A changelog of the shape.** Each time a new row changes what a practice page says, a dated note on that page.
